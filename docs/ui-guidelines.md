# 网站 UI 组件规范

- 间距采用 4px 基础单位：4 / 8 / 12 / 16 / 24 / 32。
- 全站唯一强调色为 `--accent-orange: #f47716`。控件、图标、焦点、项目详情和悬浮态均引用该变量；辅助文字使用中性灰，禁止项目数据重新覆盖全局强调色。占位 SVG 与背景视频的生成源码也采用橙色系。
- 导航、品牌和联系胶囊统一高 40px，玻璃导航条桌面/移动端高 58px，吸顶底色透明度约 28%；其他触控按钮高 44px；主要行动按钮最小高 48px。
- 导航文字 14px / 20px，按钮文字 14px / 20px，辅助标签 12px / 20px。
- 图标盒使用 16 / 20 / 24px；图标不参与弹性压缩；图文间距使用 8 / 12 / 16px。
- 导航在桌面采用左右等宽网格轨道，中间导航相对整条栏体居中；所有控件共用垂直中心线。移动端联系按钮及菜单仍保持 44px 点击高度。
- 腾讯体 W7 通过字体 ascent / descent / line-gap 指标统一校准字面位置，避免逐个按钮使用偏移补丁。
- 品牌注册符采用独立定位，不影响品牌文字行框与图标的对齐。
- 能力卡片统一内边距、标题行高与底部操作区；项目标签、联系方式行使用一致的图文对齐。
- 首屏版式固定为：眉标 → `Double K` 渐变大字（橙色渐变，`clamp(64px,10.4vw,170px)`）→ `PORTFOLIO`（字距 `.3em`）+ 倾斜 `-8°` 的签名 → 两句描述 → 行动区 → 底部作品胶卷。字号随断点收敛，移动端隐藏星芒、署名与视频按钮。
- 品牌字样全站统一为 `Double K`，大小写与空格固定，后缀 `®` / `©` 用独立定位元素，不并入文字行框。
- 首屏胶卷单张 `aspect-ratio` 桌面 2.1、移动 1.5，圆角 14px / 10px，两份内容做 `-50%` 位移循环，容器 `overflow:hidden` + 左右 mask 渐隐；触屏与 `prefers-reduced-motion` 下停止滚动。
- 基础组件及导航的唯一样式入口是 `src/ui.css`；装饰性排版与页面布局位于 `src/styles.css`。两者选择器权重相近，覆盖组件样式时优先在原文件内提权，不要再加第三处补丁。
